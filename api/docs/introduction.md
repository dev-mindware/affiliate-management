# Mindgest Partners API

Esta API foi migrada para NestJS com TypeScript e expõe a documentação interactiva em Scalar.

- API base: `http://localhost:8000/api`
- Scalar Docs embarcado: `http://localhost:8000/api/reference`
- OpenAPI JSON: `http://localhost:8000/api/openapi.json`
- Swagger UI: `http://localhost:8000/api/swagger`

Use `npm run seed` para criar o admin inicial, os serviços comerciais existentes e os planos BASE, SMART e CUSTOM do Mindgest Partners Program.
